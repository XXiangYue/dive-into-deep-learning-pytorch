# 第 1 章 引言

对应原书：`chapter_introduction`（1.1 ~ 1.6）。这一章没有模型要训，目标是把
「这本书在讲什么、每一块在第几章展开」变成一张自己能用的地图。

## 本章目标

1. 说清楚机器学习相对「人写规则」到底换了什么问题；
2. 记住四个零件：数据、模型、目标函数、优化算法，并能各举一例；
3. 能把 15 章归到自己划分的三个阶段里，知道哪些章必须手写、哪些可以先跳过；
4. 环境自检通过，后面每一章都在这个环境上叠加。

## 知识点清单

- 表示学习（representation learning）与特征工程的分界
- 监督 / 无监督 / 强化 / 半监督 / 自监督的判别标准
- 回归、分类、标注、检索、排序、推荐各自的目标函数长什么样
- 平方损失、经验风险最小化、小批量随机梯度下降（先见个面，第 3 章细讲）
- 深度学习这一轮起来的三个条件：数据、算力、算法（ReLU / Dropout / BN / 残差）
