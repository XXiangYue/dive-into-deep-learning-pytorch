# 第 2 章 预备知识

对应原书：`chapter_preliminaries`（2.1 ~ 2.7）。这是全书唯一一章「不像深度学习」的章节，
但也是唯一一章如果潦草读完、后面每一章都会卡住的章节。

## 本章目标

1. 张量的 shape / dtype / device 三件套能背下来，广播规则能徒手推形状；
2. 知道广播和原地操作分别在什么时候省时间、什么时候埋坑；
3. 能把 `sum(axis=)`、矩阵乘、范数用「行组合 / 列组合」两种视角读；
4. autograd 不只是会用 `backward()`，还要能验证雅可比、能算二阶导；
5. 概率部分要能把「交叉熵 = 负对数似然」这句话讲清楚，第 3 章要用。
