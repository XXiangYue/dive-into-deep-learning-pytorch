## 习题 2.1 证明广播规则：形状 (3,1) 与 (1,2) 可以相加

广播是从尾部对齐后逐维比较，每一维要求「相等」或「其中一个为 1」。

对这两组：第 2 维是 $1$ 与 $2$，其中一个是 1，可广播，结果取 $2$；
第 1 维是 $3$ 与 $1$，其中一个是 1，可广播，结果取 $3$。
因此结果形状为 $(3,2)$，且

$$c_{ij} = a_{i1} + b_{1j}$$

可以理解为「把 $a$ 沿第 2 维复制 2 份、把 $b$ 沿第 1 维复制 3 份再相加」。
所谓广播只是逻辑上的复制，实际实现按索引取元素，不产生额外内存。

## 习题 2.2 (3,) 与 (3,2) 为什么不能广播，怎么改

`(3,)` 会先被补成 `(1,3)`。尾部对齐后比较 $3$ 与 $2$：既不相等、也都不是 1，报错。
两种改法：

```python
a.reshape(3, 1) + b     # 变成 (3,1)+(3,2) -> (3,2)，每行加同一个标量
a.reshape(1, 3) + b     # 变成 (1,3)+(3,2) -> 报错，因为 3 != 2
```

**关键：`(3,)` 到底该理解成行还是列，取决于你想让它和哪一维对齐。** numpy 默认补在前面（当成行向量），
所以想让每个样本加一个常数必须显式写 `reshape(-1, 1)`。这是我从零实现线性回归时踩的第一个坑。

## 习题 2.3 `reshape` 和 `view` 的区别

`view` 要求张量在内存里连续（contiguous），只改元信息，零拷贝，最快；
`reshape` 先尝试 view，不行就拷贝一份再变形。

```python
x = torch.arange(12).reshape(3, 4)
x.t().view(12)      # 报错：transpose 之后不连续
x.t().reshape(12)   # 可以：内部复制了一份
```

验证连续性用 `x.is_contiguous()`。我原以为 `.t().view()` 能省一次拷贝，实际不行，
因为转置只换了 stride，内存排布还是原来的行优先。

## 习题 2.4 求 $\|\mathbf{x}\|_2$ 对 $\mathbf{x}$ 的梯度

$$\|\mathbf{x}\|_2 = \left(\sum_i x_i^2\right)^{1/2}$$

用链式法则，令 $u = \sum_i x_i^2$，则 $\|\mathbf{x}\|_2 = u^{1/2}$：

$$\frac{\partial \|\mathbf{x}\|_2}{\partial x_j} = \frac{1}{2}u^{-1/2}\cdot 2x_j = \frac{x_j}{\|\mathbf{x}\|_2}$$

所以 $\nabla_{\mathbf{x}}\|\mathbf{x}\|_2 = \mathbf{x}/\|\mathbf{x}\|_2$，正好是单位方向向量。
$\mathbf{x}=\mathbf{0}$ 时不可导（0 处有尖点），这也是 L2 正则很少在 0 附近出问题的原因——
它本来就想把参数压向 0，梯度在 0 附近趋于 0 反而是好事。

用 `code/03_autograd.py` 的写法可以验证：`x = torch.randn(5, requires_grad=True)`，
`x.norm().backward()` 后比较 `x.grad` 与 `x / x.norm()`，误差在 1e-7 量级。

## 习题 2.5 用抽样验证两点分布的方差公式

理论：$X \sim \text{Bernoulli}(p)$，$\mathrm{Var}[X] = p(1-p)$。取 $p=0.3$，理论方差 $0.21$。

```python
import torch
p, n = 0.3, 1_000_000
x = (torch.rand(n) < p).float()
print(x.mean(), x.var(unbiased=False))   # 0.2999..., 0.2100...
```

`x.var()` 默认是**无偏**估计（除以 $n-1$），要和 $p(1-p)$ 比就得写 `unbiased=False`。
我第一次没加这个参数，n=1000 时差到 0.0002，还以为是抽样误差，其实是自由度的问题。

## 习题 2.6（半途）证明反向传播的内存复杂度是 O(节点数)
