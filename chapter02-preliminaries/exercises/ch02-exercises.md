# 第 2 章 习题与解答

## 习题 2.1 证明广播规则：形状 (3,1) 与 (1,2) 可以相加

广播是从尾部对齐后逐维比较，每一维要求「相等」或「其中一个为 1」。

对这两组：第 2 维是 $1$ 与 $2$，其中一个是 1，可广播，结果取 $2$；
第 1 维是 $3$ 与 $1$，其中一个是 1，可广播，结果取 $3$。
因此结果形状为 $(3,2)$，且

$$c_{ij} = a_{i1} + b_{1j}$$

可以理解为「把 $a$ 沿第 2 维复制 2 份、把 $b$ 沿第 1 维复制 3 份再相加」。
所谓广播只是逻辑上的复制，实际实现按索引取元素，不产生额外内存。

## 习题 2.2 (3,) 与 (3,2) 为什么不能广播，怎么改

`(3,)` 会先被补成 `(1,3)`。尾部对齐后比较 $3$ 与 $2$：既不相等、也都不是 1，报错。
两种改法：

```python
a.reshape(3, 1) + b     # 变成 (3,1)+(3,2) -> (3,2)，每行加同一个标量
a.reshape(1, 3) + b     # 变成 (1,3)+(3,2) -> 报错，因为 3 != 2
```

**关键：`(3,)` 到底该理解成行还是列，取决于你想让它和哪一维对齐。** numpy 默认补在前面（当成行向量），
所以想让每个样本加一个常数必须显式写 `reshape(-1, 1)`。这是我从零实现线性回归时踩的第一个坑。

## 习题 2.3 `reshape` 和 `view` 的区别

`view` 要求张量在内存里连续（contiguous），只改元信息，零拷贝，最快；
`reshape` 先尝试 view，不行就拷贝一份再变形。

```python
x = torch.arange(12).reshape(3, 4)
x.t().view(12)      # 报错：transpose 之后不连续
x.t().reshape(12)   # 可以：内部复制了一份
```

验证连续性用 `x.is_contiguous()`。我原以为 `.t().view()` 能省一次拷贝，实际不行，
因为转置只换了 stride，内存排布还是原来的行优先。
