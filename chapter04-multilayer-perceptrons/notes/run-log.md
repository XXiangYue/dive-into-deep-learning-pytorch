# 第 4 章 运行记录

环境同前：Windows 11 / Python 3.12.10 / torch 2.4.1+cpu。

## 2025-11-28 19:10 初始化尺度对梯度的影响

```bash
python code/01_mlp_scratch.py
```

先只看第一步：

```text
=== 初始化尺度 vs 第一步梯度范数 ===
Xavier     初始 loss 0.6931  梯度范数 2.14
std=0.5    初始 loss 0.6931  梯度范数 18.76
std=1.0    初始 loss 0.6931  梯度范数 1204.35
```

初始 loss 都是 0.6931 = ln 2，符合预期（两类、初始化输出接近 0），
但梯度范数差了三个数量级。std=1.0 时第一步的梯度范数是 Xavier 的 560 倍，
按 lr=0.1 走一步，参数直接被甩到很远的地方。

`std=0.5` 这个数字很有意思：$n_{in}=2$ 时 Xavier 给的标准差是
$\sqrt{2/(2+16)} = 0.333$，0.5 是它的 1.5 倍，梯度范数就大了 8.8 倍。
说明这个任务的梯度对初始化相当敏感。

## 2025-11-28 19:20 std=1.0 到底会不会崩

把 `train` 里的 init 换成 `std=1.0` 跑 30 个 epoch：

```text
epoch  1  loss 2.4131  acc 0.600
epoch  2  loss nan     acc 0.515
```

第 2 个 epoch 就 nan。这印证了 4.7 的分析：方差在层间被放大 $n_{in}\sigma^2 = 2$
倍，两层就是 4 倍，再乘上 200 个样本的累积，直接溢出。
**结论：初始化不是「随便给个小随机数」就行，Xavier 的系数是必需的。**

## 2025-11-28 19:45 Xavier 正常训练

```text

epoch  5  loss 0.3862  acc 0.845
epoch 10  loss 0.2941  acc 0.895
epoch 15  loss 0.2273  acc 0.920
epoch 20  loss 0.1898  acc 0.925
epoch 25  loss 0.1721  acc 0.930

最终 loss 0.1655  acc 0.940

```

loss 从 0.693 掉到 0.1655，acc 从 0.5 附近升到 0.940，中间没有反弹。
参数量 82 和手算一致。

作为对照，同一份数据用线性模型（第 3 章的 softmax 回归）只能到 0.86 左右——
这就是隐藏层带来的 8 个百分点。
