## 4.1 隐藏层与激活函数

### 两层网络的定义

$$\mathbf{H} = \sigma(\mathbf{X}\mathbf{W}_1 + \mathbf{b}_1), \qquad
\mathbf{O} = \mathbf{H}\mathbf{W}_2 + \mathbf{b}_2$$

$\mathbf{X} \in \mathbb{R}^{n\times d}$，$\mathbf{W}_1 \in \mathbb{R}^{d\times h}$，
$\mathbf{W}_2 \in \mathbb{R}^{h\times q}$。若 $\sigma$ 是恒等映射，则

$$\mathbf{O} = (\mathbf{X}\mathbf{W}_1 + \mathbf{b}_1)\mathbf{W}_2 + \mathbf{b}_2
= \mathbf{X}\underbrace{(\mathbf{W}_1\mathbf{W}_2)}_{\mathbf{W}'} + \underbrace{(\mathbf{b}_1\mathbf{W}_2 + \mathbf{b}_2)}_{\mathbf{b}'}$$

也就是说，**两层仿射变换的复合等价于一层**，参数量从 $dh + hq$ 退化成 $dq$，
表达能力反而下降。所以激活函数不是「加个点缀」，它是隐藏层存在的唯一理由。

### 三个激活函数

$$\mathrm{ReLU}(x) = \max(x, 0), \qquad
\mathrm{sigmoid}(x) = \frac{1}{1+e^{-x}}, \qquad
\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

导数：

$$\mathrm{ReLU}'(x) = \mathbb{1}[x > 0], \qquad
\mathrm{sigmoid}'(x) = \mathrm{sigmoid}(x)\left(1 - \mathrm{sigmoid}(x)\right) \le \frac{1}{4}$$

**我为什么选 ReLU 做默认：** sigmoid 的导数最大只有 0.25，多层连乘之后梯度按
$0.25^L$ 衰减，10 层就是 $10^{-6}$；ReLU 在正半轴的导数恒为 1，梯度不会因为层数衰减。
代价是负半轴梯度为 0（「神经元死亡」），实践里靠小学习率和合理初始化避开。

ReLU 在 $x=0$ 处不可导，PyTorch 里取次梯度 0。理论上不严谨，实践上完全没问题——
随机初始化下恰好落在 0 的概率是 0。

### 通用近似定理

含一个隐藏层、足够多神经元的网络可以以任意精度逼近紧集上的连续函数。
**我的判断：这个定理不该被过度解读。** 它只说「存在」，没说「梯度下降能找到」，
也没说「需要多少神经元」。所以「理论上一个隐藏层就够」这句话对实践没有指导意义，
真正决定深度的是「表示效率」：深网络用指数少的参数表达某些函数。

## 4.2 从零实现：参数量和更新顺序

### 参数量

$d=2, h=16, q=2$：

| 参数 | 形状 | 个数 |
|---|---|---|
| $\mathbf{W}_1$ | $2\times16$ | 32 |
| $\mathbf{b}_1$ | $16$ | 16 |
| $\mathbf{W}_2$ | $16\times2$ | 32 |
| $\mathbf{b}_2$ | $2$ | 2 |
| 合计 | | **82** |

一般公式：$dh + h + hq + q$。第 1 章的线性模型在这个任务上只有 $2\times2+2 = 6$ 个参数，
换成 MLP 是 82 个，13 倍——这就是「容量」的具体含义。

### 手写 SGD 的顺序

```python
loss = F.cross_entropy(mlp(Xb, params), yb)   # 1. 前向 + 损失
loss.backward()                                # 2. 反传，梯度累加到 .grad
with torch.no_grad():
    for p in params:
        p -= lr * p.grad                       # 3. 更新
        p.grad.zero_()                         # 4. 清零
```

**注意这里没有除以 `batch_size`。** 因为 `F.cross_entropy` 默认 `reduction='mean'`，
梯度已经是平均值；而第 3 章从零写线性回归时用的是 `.sum()`，所以要自己除。
两者必须恰好除一次，这是我从第 3 章带过来的教训，写在注释里防止以后再错。

### 参数用 list 管

从零版把四个参数放进一个 list，好处是更新和清零都是一个 for 循环；
坏处是没有名字，调试时只能靠下标。第 5 章会用 `nn.Parameter` 和 `named_parameters()`
解决这个问题——那一章就是专门讲「参数怎么管理」的。

## 4.3 简洁实现：只有模型那一段变了

```python
net = nn.Sequential(nn.Flatten(), nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 2))

def init_weights(m):
    if isinstance(m, nn.Linear):
        nn.init.normal_(m.weight, std=0.01)
        nn.init.zeros_(m.bias)

net.apply(init_weights)
```

三个观察：

1. **`net.apply(fn)` 是深度优先递归**，对每个子模块调用一次 `fn`。
   所以 `fn` 里必须自己判断类型，否则会对 `ReLU` 这类无参数层报错。
2. **训练循环一个字都不用改。** 把 `net(X)` 换进去就行，因为交叉熵、优化器、
   批量迭代都是通用的。我一开始又抄了一遍循环，白写了 20 行。
3. **`Flatten()` 在这里其实没用**（输入已经是二维），但留着不亏：
   后面换成图像数据（四维）时不用改结构。这是个习惯问题。

### 初始化为什么要自己写

`nn.Linear` 默认用 $U(-\sqrt{1/n_{in}}, \sqrt{1/n_{in}})$ 初始化，量级大概 $0.5/\sqrt{n_{in}}$。
对 2→16 这种小层，默认值偏大，配合 lr=0.1 会让 loss 在前几个 batch 抖得厉害。
我改成 `std=0.01` 是为了和从零版对齐，方便对照 loss 曲线——不是因为它更好。
真正有理论依据的初始化是 4.7 的 Xavier。

## 4.4 模型选择、欠拟合与过拟合

### 两个误差

- **训练误差** $R_{emp}$：在训练集上的平均损失；
- **泛化误差** $R$：在真实分布上的期望损失。

我们只能看到前者，想要的却是后者。两者之差叫泛化 Gap，它随模型容量先降后升：

```text
误差
 ↑        ┌── 泛化误差
 │      ╱   ╲
 │    ╱      ╲──────── 训练误差
 │  ╱
 └──────────────────→ 模型容量
      欠拟合 | 合适 | 过拟合
```

### 判定方法（我实际用的）

| 现象 | 结论 |
|---|---|
| 训练 loss 高、验证 loss 也高 | 欠拟合：模型太小或训练不够 |
| 训练 loss 很低、验证 loss 高 | 过拟合：容量相对数据太大 |
| 两者都低但 gap 大 | 过拟合早期，加正则或加数据 |

第 3 章 softmax 那组数据：train acc 0.941 / val acc 0.940，gap 0.001，属于「都低且贴合」，
不需要任何正则。而这一章 `code/02` 的多项式回归：train loss 0.0031 / val loss 0.184，
gap 是 60 倍，典型的过拟合。

### 容量由三个东西共同决定

$$\text{有效容量} \approx f(\text{参数个数},\ \text{数据量},\ \text{正则强度})$$

**我的判断：不要只盯着参数个数。** 20 个样本、400 个参数一定过拟合；
但 100 万样本、400 个参数就欠拟合了。所以「这个模型是不是太大」这个问题
离开数据量没有意义。这也是为什么正则化等价于「缩小有效参数量」——
它没减少参数，只是让参数不能自由取值。

### 一条实践准则

先不加任何正则，把模型训到训练误差接近 0（确认它有拟合能力），
再加正则把它拉回来。反过来做（一上来就加 dropout + 权重衰减）会分不清
「模型不行」还是「正则太强」。这一章我就是按这个顺序做的。

## 4.5 权重衰减

### 目标函数

$$L(\mathbf{w}, b) + \frac{\lambda}{2}\|\mathbf{w}\|_2^2$$

$\lambda > 0$ 是超参。$\frac{1}{2}$ 还是为了让平方的导数 2 消掉。

### 小批量 SGD 的更新式

$$\mathbf{w} \leftarrow \mathbf{w} - \eta\left(\frac{1}{|\mathcal{B}|}\sum_{i\in\mathcal{B}}\nabla_{\mathbf{w}} l^{(i)} + \lambda\mathbf{w}\right)
= (1 - \eta\lambda)\mathbf{w} - \eta\,\mathbf{g}$$

其中 $\mathbf{g}$ 是原来那部分梯度。所以权重衰减就是**每步先把权重乘上一个略小于 1 的系数**，
再沿梯度走。

**我为什么叫它「衰减」：** 因为 $(1-\eta\lambda) < 1$，不管梯度是什么，
权重每一轮都会被「拉回」原点一点。$\eta\lambda \ge 1$ 时权重会震荡甚至发散，
所以 $\lambda$ 的量级要配合学习率看：lr=0.01 时 $\lambda = 10^{-2}$ 相当于每步乘 0.9999，
很温和；lr=0.5 时同样的 $\lambda$ 就危险了。

### 只衰减 weight，不衰减 bias

这个细节 d2l 书里强调过，我第一版忽略了，代价见 run-log。
理由：偏置控制的是「整体平移」，它不放大输入的差异；而过拟合往往来自
某些特征的系数被推到很大。把 bias 也压向 0，等于强制模型输出均值接近 0，
在数据均值不为 0 的任务上直接造成欠拟合。

### 和「限制参数范数」的等价性

约束 $\|\mathbf{w}\|_2 \le c$ 的拉格朗日形式就是 $L + \lambda(\|\mathbf{w}\|_2 - c)$，
所以 L2 正则等价于对权重做软约束。$\lambda$ 越大，允许的球越小，有效容量越低。

## 4.6 dropout

### 做法

训练时对每个隐藏单元独立地以概率 $p$ 置零：

$$h'_i = \begin{cases} 0, & \text{以概率 } p \\ h_i / (1-p), & \text{以概率 } 1-p \end{cases}$$

后一种写法叫 **inverted dropout**，是现在所有框架的默认做法。

### 为什么训练时要除以 $(1-p)$

设输入 $h_i$ 的期望是 $\mathbb{E}[h_i]$。不加缩放时，训练期输出的期望是
$(1-p)\mathbb{E}[h_i]$；而推理期不丢任何单元，输出期望是 $\mathbb{E}[h_i]$。
两者不一致，相当于推理时把每个隐藏层的激活放大了 $1/(1-p)$ 倍，多层叠加就爆了。

两种修法：

1. 训练不缩放、推理时全乘 $(1-p)$（原论文写法）；
2. **训练时除以 $(1-p)$、推理时原样输出**（inverted，现在常用）。

第二种的好处是推理路径完全没有额外操作，部署时不用记着「这个模型要不要乘系数」。

### 我踩的坑

第一版两处都没缩放（训练置零、推理原样），结果验证损失比不加 dropout 还差。
原因就是上面说的期望不一致。当时我以为是「dropout 对我这个任务没用」，
差点把它删了，后来把训练期的输出均值打印出来才看明白。

### 只在训练时开

`net.train()` / `net.eval()` 必须切。我第一版忘了切，验证时还在随机丢神经元，
导致同一个模型每次评估结果都不一样，val acc 在 0.83~0.87 之间跳。
这个错误很隐蔽，因为 loss 曲线看起来「只是在抖」。

### 为什么它算正则

把 dropout 看成对 $2^n$ 个「子网络」做集成（每个 mask 一个子网络），
推理时用的是它们的平均。集成模型的方差比单个模型小，所以泛化更好。
这个解释不严格（子网络共享参数，不是独立的），但方向是对的。
