# 第 4 章 多层感知机

对应原书：`chapter_multilayer-perceptrons`（4.1 ~ 4.7）。这一章真正开始讲「深度」：
加一个隐藏层就有非线性，但有了容量就会过拟合，于是要用权重衰减、dropout 去压，
压的时候又会碰到数值稳定性问题——三件事是串在一起的，不能分开学。

## 本章目标

1. 能证明「两层线性叠加还是线性」，从而说清激活函数不可省；
2. 从零写出两层 MLP 的前向与训练循环，参数、梯度都手动管；
3. 故意造一个过拟合的配置（20 个样本 + 20 维多项式特征），再用权重衰减压下去；
4. 手写 dropout，搞清训练期和推理期的缩放关系；
5. 用梯度范数的数字体会「初始化太大 → 梯度爆炸」，并解释 Xavier 的公式。

## 数据

全部合成，不下载任何东西：

- `code/01`、`code/03` 用 `sklearn.datasets.make_moons`（200 个点，两个交错半月）；
- `code/02` 用一个已知的三次多项式 + 噪声造 20 个训练点、100 个测试点。

选择 make_moons 的理由：线性模型在它上面必然欠拟合（准确率卡在 0.86 左右），
加一个隐藏层就能到 0.95 以上，差异非常直观。

## 三条能带走的结论

1. **初始化不是随便给个小随机数。** 梯度范数对初始方差极其敏感，实测差三个数量级。
2. **正则化要区分参数。** bias 不该衰减，否则等于强行让模型穿过原点。
3. **训练期和推理期的期望必须对齐。** dropout 的缩放、BN 的 running stats
   都遵循同一条原则，第 7 章讲 BN 时会再遇到一次。
